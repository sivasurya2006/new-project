#  QR Code Generator
A fast, customizable, and responsive QR Code Generator web application built with **HTML5, CSS3, and Vanilla JavaScript**.
---
##  Features
-  **Instant QR Generation**: Generate QR codes from any text or URL.
-  **Style Customization**: Choose QR size (150px to 400px) and custom colors.
-  **Download as PNG**: Save high-resolution QR codes directly to your device.
-  **Recent History**: Automatically saves recent QR codes using `localStorage`.
-  **Dark & Light Mode**: Toggle between dark and light themes.
-  **Copy to Clipboard**: Quick buttons to copy text or QR image.
-  **Keyboard Shortcut**: Press `Enter` to instantly generate.
